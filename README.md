# West Cap Event Platform — Website Builder + Recruiter Notifications

Start with **MONDAY-HIRES-UPDATE.md** for the new board and source reporting, then **NOTIFICATIONS-SETUP.md** for deployment, sender setup and daily reminders. **EVENT-WEBSITES-START-HERE.md** covers the optional event website builder.

Existing registration, Bonzo campaigns, Calendly, attendee import, Monday ROI and admin controls remain included. Notifications require email setup and are disabled until enabled in admin.

Run `npm ci`, `npm test`, and `npm run build`.

See **PHOTO-UPLOADS.md** for selecting gallery photos directly from your computer.
