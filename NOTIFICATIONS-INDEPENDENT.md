Recruiter notifications are independent of Monday

Registrations and confirmed attendee imports queue notices for the assigned recruiter at their saved email address. Daily summaries continue until reminders are stopped manually using the email link or Admin. Archiving an event, removing an imported attendee, and deactivating a recruiter still pause their reminders. Monday credentials, groups, statuses, and matches never gate email delivery. Existing manual opt-outs and send receipts are preserved. Old automatic Monday completion records no longer suppress reminders.

Deploy this complete project including functions to the existing Netlify site. Refresh the admin page, save Notifications On, then use Retry pending notifications. This can send all pending recruiter notices. Keep the existing Gmail and notification secret settings. Monday source and ROI reporting remains available independently.
